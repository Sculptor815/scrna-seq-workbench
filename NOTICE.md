# Provenance

This project refactors the user's MIT-licensed Kimi scRNA-seq analysis prototype.
The workflows were rewritten with shared validation, stage contracts and explicit
review gates; the original MIT notice is retained in LICENSE. DeepSeek and Kimi
are development collaborators, not required runtime model providers.

Scanpy, scvi-tools, PyDESeq2 and their dependencies retain their own licenses.
HPA datasets and sequencing-company reports are NOT bundled. Cite and comply
with the exact reference release used in a run. No private datasets, vendor
screenshots, credentials or personal filesystem paths belong in this repository.
