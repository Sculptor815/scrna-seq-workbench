# AI report archival checks

The archival scope is limited to the two submitted overview reports, the three linked second-run cohort reports, selected presentation figures, English summaries and file manifests. No cell-level annotation/QC tables, expression matrices, full marker rankings or bulk numerical result datasets are published.

Original report/figure files are copied byte-for-byte and checked against their sources. The original Chinese HTML remains unchanged. English navigation is supplied at the README paths referenced by those reports. Report-internal links to unpublished local tables or configurations are recorded in each manifest; those links require the original local output directory.

This operation checks archival integrity and summary consistency. It does not rerun the scientific analyses or independently repeat their reported validation. Candidate labels remain unreviewed, and the manual submission is unchanged. Both AI reports used PCA, not scVI. Cell-cycle correction and multi-neighbor selection are not demonstrated in the supplied historical records.

See the [AI 1 manifest](ai-01/source_manifest.json) and [AI 2 manifest](ai-02/source_manifest.json).
