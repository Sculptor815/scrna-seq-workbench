# Original AI reports

The original Chinese HTML reports and selected presentation figures are preserved byte-for-byte. The [English summary](../README.md) provides GitHub-readable navigation and the analysis scope.

Download the HTML for browser viewing. Figures are embedded in the reports. In the second run, keep the FL, YS and hESC subdirectories alongside the overview to follow its three report links.

Original HTML links to CSV tables, configurations and local analysis notes are preserved, but these supporting files remain in the user's local analysis directory and are not published in this report-only archive. The [manifest](../source_manifest.json) identifies those local-only links. Per-cell data, expression matrices, full marker tables and other bulk numerical datasets are not included.
