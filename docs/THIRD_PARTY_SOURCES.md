# Third-party sources

The repository's MIT license covers its original code and documentation, not the linked publications, externally hosted images, reference atlases or public datasets. Each retains its original terms. We link to original figure pages and externally hosted images rather than commit full papers or relabel their figures as our own. Broken/restricted source assets remain marked unavailable.

Original studies, figure URLs, representation types and caveats are in [the figure manifest](../benchmarks/original_figures.json). Public input locations and exact download hashes are in [the data source record](../benchmarks/legacy/sources.json). Derived benchmark tables and plots must retain those citations and provenance if redistributed.

Method sources: [HPA](HPA_METHODS.md), [Scanpy](https://scanpy.readthedocs.io/), [scvi-tools](https://docs.scvi-tools.org/), [PyDESeq2](https://pydeseq2.readthedocs.io/). Client packaging sources are in [HOSTS.md](HOSTS.md). The project is independent and is not endorsed by these organizations.
