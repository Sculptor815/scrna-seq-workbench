# v0.2.0 research preview

Five guided analysis Skills for Codex and Claude Code, with generated DeepSeek
Harness project entries. English documentation, shared intake, raw-count contracts,
HPA-guided marker evidence and manual hierarchical review are included.

Five public-study comparison figures and review packets are included in the
repository package. These retain historical marker-baseline predictions. Human
HPA-style review is pending; no improved annotation accuracy is claimed. Three
original publication figures are externally displayed; two originals remain
unavailable and are linked with an explicit access note.

Choose the **plugin** ZIP for the standalone plugin directory. Choose the
**repository** ZIP or a Git clone for examples, benchmark figures and DeepSeek
Harness project discovery. Neither ZIP includes raw count matrices or models.
Python dependencies must be installed separately.

This is a prerelease. Consult validation.json and the actual GitHub Actions results.
Live host conversations and full biological validation remain separate acceptance
tasks. The project is independent of HPA and the supported host vendors.
